### Week 1 Objectives:

- Familiarize with the working environment, team members, and regulations of the First Cloud AI Journey (FCAJ) program.
- Understand basic Cloud Computing concepts and how to navigate the AWS Management Console.
- Create and secure an AWS Account (Free Tier).
- Complete the 5 "Explore AWS" hands-on tasks to earn $100 in AWS Credits for the upcoming internship project.
- Master Cost Management (FinOps) processes and safe resource cleanup (Resource Lifecycle).
- Form a team to prepare for the actual project implementation phase.
